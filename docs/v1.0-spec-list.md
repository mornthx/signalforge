## 5. V1 architectural invariants

These invariants are V1's load-bearing assumptions. Any V1.5+
or V2 work must respect them or document the breaking change
in a new ADR + new tag.

1. **Single-threaded UI**. Qt's main thread is the only
   thread that mutates UI state. All worker threads
   communicate via `Qt::QueuedConnection` (live mode) or
   direct calls into thread-safe sinks (M11 / M12 replay
   path).
2. **Lock-free reader path through `SignalBuffer`**. Chart
   reads use atomic snapshot pointers (M6 + ADR-005); no
   mutex on the chart-render path.
3. **Bounded staleness ≤ 1 ms** on the chart UI. Live data
   reaches charts within 1 ms of arrival under normal load.
4. **Driver workers in background `QThread`**. Per ADR-002,
   each connection's driver runs on its own QThread; main
   thread is never blocked by driver I/O.
5. **Real-time playback timing accuracy**. Per M12 S3,
   replay 1× speed dispatches with < 5 % wall-clock
   error (V1.0 measured: 0.01 %).
6. **All-signals recording**. V1 records every signal a
   connected decoder emits; no per-signal filter (M10
   §3.4).
7. **Lossless round-trip**. SFREPLAY v1 → SessionReader →
   SignalValueSink delivers bit-identical events including
   binary string payloads (M10 HALT trigger #2 gate).
